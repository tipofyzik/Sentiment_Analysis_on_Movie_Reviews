Configuration file (config.yml) contains settings for different stages of data preprocessing, feature extraction, model training, and saving results. The file consists of 4 main parameter categories:

· paths:
  — datasets:
    — stanford_movie_reviews: Path to the Stanford Movie Reviews dataset in .csv format.
    — sar14_txt: Path to the SAR14 dataset in .txt format.
    — sar14_csv: Path to the SAR14 dataset in .csv format.
  — cleaned_datasets:
    — stanford_movie_reviews: Path to the cleaned Stanford Movie Reviews dataset. Used to avoid repeating the preprocessing stage.
    — sar14: Path to the cleaned SAR14 dataset. Used to avoid repeating the preprocessing stage.
  — features: Directory where feature extraction artifacts (vectorizers and embeddings) are stored.
  — results: Root directory for storing training results.
  — models:
    — tfidf_vectorizer: Path to the saved TF-IDF vectorizer used to preprocess custom reviews.
    — word2vec: Path to the saved Word2Vec model used to generate word embeddings for custom reviews.
  — result_models:
    — tfidf: Directory for models trained on TF-IDF features.
    — word2vec: Directory for models trained on Word2Vec features.

· preprocessing:
  — data_is_preprocessed: Indicates whether the datasets have already been preprocessed. If false, the original datasets will be cleaned and saved to the paths specified in paths.cleaned_datasets. If true, the cleaned datasets will be loaded directly.
  — spacy:
    — batch_size: Number of reviews processed simultaneously by spaCy to improve preprocessing performance.
    — n_process: Number of worker processes used by spaCy during preprocessing. Set to -1 to use all available CPU cores.

· feature_extraction:
  — balance_datasets: Determines whether the dataset classes should be balanced before training. If true, the majority class will be downsampled to match the minority class.
  — tfidf:
    — enabled: Enables or disables TF-IDF feature extraction.
  — word2vec:
    — enabled: Enables or disables Word2Vec feature extraction.

· training:
  — test_size: Fraction of the dataset reserved for testing during the train-test split.
  — training_number: Number of independent training runs. This parameter can be used to evaluate model stability across multiple runs.
  — random_state: Random seed used for dataset splitting and machine learning models to ensure reproducibility.
  — models:
    — logistic_regression: Indicates whether the Logistic Regression model has already been trained. If false, the model will be trained; otherwise, training will be skipped.
    — naive_bayes: Indicates whether the Naive Bayes model has already been trained.
    — random_forest: Indicates whether the Random Forest model has already been trained.
    — linear_svc: Indicates whether the Linear Support Vector Classifier has already been trained.
